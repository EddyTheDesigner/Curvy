# Changelog

## 1.1.0

- Put the complete 25-curve reference set at the front of the built-in gallery.
- Add clearly named Ease In and Ease Out presets and the reference Ease curve (`0.42, 0, 0.58, 1`).
- Preserve the original native Ease curve as AE Easy Ease and retain the extra Sine, CSS, and Snappy curves: 34 presets in total.
- Upgrade saved built-in libraries without replacing custom curves or libraries. Apply the upgrade once so intentionally removed presets stay removed afterward.

- Package reviewed source, documentation, screenshots, and the standalone panel. Exclude development tests and local working files.

- Initial native EffectCraft curve editor, preset gallery, reusable libraries, Flow-compatible import/export, and exact curve expressions.
